Cloud Computing y Tecnologías de Virtualización

Fundamentos de computación en la nube, modelos de servicio y tecnologías de aislamiento de cargas de trabajo.

Cloud Computing

Modelo de prestación bajo demanda de recursos informáticos (servidores, almacenamiento, bases de datos, redes y software) a través de Internet, con escalabilidad elástica y pago por uso.

SaaS (Software as a Service)

Modelo donde las aplicaciones completas se alojan en la nube y el usuario accede a ellas mediante un navegador web o cliente ligero sin gestionar infraestructura ni instalaciones locales (ej. Google Workspace, Microsoft 365).

PaaS (Platform as a Service)

Entorno completo de desarrollo y despliegue en la nube que proporciona hardware, sistema operativo, motores de bases de datos y herramientas de ejecución para centrarse únicamente en programar (ej. Heroku, Google App Engine).

IaaS (Infrastructure as a Service)

Suministro de recursos fundamentales de cómputo virtualizado, redes y almacenamiento en la nube. El administrador mantiene el control total sobre los sistemas operativos y aplicaciones desplegadas (ej. AWS EC2, Azure VMs).

Virtualización

Tecnología que permite dividir un servidor físico en múltiples máquinas virtuales (VM) independientes mediante un hipervisor, optimizando el aprovechamiento del hardware y aislando cada sistema operativo.

Docker

Plataforma de código abierto que empaqueta aplicaciones y todas sus dependencias dentro de contenedores ligeros y portables que comparten el kernel del sistema anfitrión, garantizando ejecución uniforme en cualquier entorno.
